# Prompt pra colar no seu Claude

Abra uma sessão nova do Claude Code, cole o texto abaixo e reserve meia hora pra conversa. Responda uma pergunta por vez. No fim, ele mostra o arquivo antes de salvar.

```
Quero mexer no meu CLAUDE.md pra ele ficar bom.
Use como referência o repositório https://github.com/Expert-Integrado-Alunos/claude-md-do-eric (leia o README, o exemplo comentado e o template).
Mas as regras têm que ser as MINHAS: meu trabalho não é o do Eric.
Me faça as perguntas que precisar, uma de cada vez: quem eu sou, como eu gosto que você me responda, quais ferramentas eu uso, o que você nunca pode fazer sem me perguntar, o que já deu errado entre nós.
Depois escreva o meu CLAUDE.md global, curto, com as regras inegociáveis no topo, e me mostre antes de salvar.
```

## Manutenção: uma frase por vez

Sempre que ele fizer algo que você não queria, não corrija só a resposta. Corrija a regra:

```
Salva no teu CLAUDE.md que eu sempre quero textos curtos.
```

```
Salva no teu CLAUDE.md que antes de mandar qualquer mensagem pra cliente você me mostra e espera meu OK.
```

```
Salva no teu CLAUDE.md que quando eu falar "manda pra equipe" é no chat interno, nunca no WhatsApp.
```

## Se você usa o Expert Brain

Peça também:

```
Adicione ao meu CLAUDE.md o bloco de memória externa que está em template/bloco-memoria-externa.md do repositório, adaptado pro meu uso.
```
